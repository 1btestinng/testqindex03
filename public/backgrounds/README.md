# QIndex Background Artwork

Place the website background artwork in this folder.

Expected files:
- `qindex-background-desktop.jpg` — desktop/tablet background
- `qindex-background-mobile.jpg` — mobile background

Recommended:
- Desktop: wide landscape artwork, ideally 2400px+ wide
- Mobile: portrait artwork, ideally 1200px+ tall
- JPG or WebP is preferred for large artwork
- Keep important visual details away from the edges where possible

The site can then use these two assets responsively.
